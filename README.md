# TOUCHLINE

설치와 회원가입 없이 브라우저에서 실행하는 한국어 축구 감독 시뮬레이션입니다.

## 실행

`index.html`을 Chrome 또는 Edge로 열거나 `게임 시작.bat`을 더블클릭하세요.
이 채팅에서 실행 중인 미리보기: http://127.0.0.1:8765

직접 서버를 실행하려면 이 폴더에서 `python -m http.server 8765 --bind 127.0.0.1`을 사용하세요.

자동 저장은 큰 경기 기록을 담을 수 있는 브라우저 IndexedDB를 사용합니다. 기존 localStorage 저장은 최초 실행 시 읽어 옮기며 원본은 보존합니다. 저장 완료는 쓰기 작업이 실제로 끝난 뒤 표시됩니다.

이전 버전에서 저장 공간 오류가 났다면 페이지를 `Ctrl+F5`로 새로고침한 후 **나의 감독 커리어 → 저장 파일 불러오기**에서 내려받은 JSON을 선택하세요. 같은 브라우저와 주소에서 계속 플레이해야 자동 저장을 다시 읽을 수 있습니다. 파일 불러오기는 최대 100MB까지 지원합니다.

## 감독 커리어

### 전술·검색·리그 기록 확장

- 전술 보드의 **움직임 설계**에서 선수 선택 → 공 소유/수비 선택 → 피치 클릭으로 두 상황의 위치를 지정합니다. 숫자 입력으로도 조절할 수 있습니다. 자기 진영에서 상대 골문으로 공격 방향은 항상 오른쪽입니다.
- 선수별 드리블·슈팅 빈도·크로스·마킹을 추가했습니다. 이동 위치와 주변 수비 간격, 패스 연결 거리, 선수 능력이 슈팅 선택과 기회 확률에 반영됩니다. 3개의 이름 있는 전술에 팀 전술·개인 지시·좌표를 저장하고 불러올 수 있습니다.
- 검색에 나이 범위·주급·계약 잔여 기간·체력·출전/영입 가능 상태·두 능력치 동시 조건과 추가 정렬을 제공합니다. 예산 이내·23세 이하·자유 계약 빠른 필터, 최대 3명 능력 비교를 지원합니다.
- 스쿼드의 **리그 기록**에서 출전·득점·리그 득점 순위·도움·출전 분·90분당 득점·슈팅/유효슈팅·무실점 경기를 확인합니다. 검색·포지션·출전 가능 필터와 정렬을 지원합니다.
- 기존 저장의 출전·득점은 유지합니다. 과거에 없던 세부 기록은 업데이트 이후 경기만 집계하고 표에 기록 범위를 표시합니다. 컵 기록은 리그 기록에 섞지 않으며 시즌이 바뀌면 초기화합니다.
- 슈팅에서 유효슈팅과 득점을 판정하고 패스 기여자에게 도움을 기록합니다. 분 단위 관전과 연속 경기의 우리 팀 경기는 같은 계산 경로를 사용합니다. 교체 시간은 출전 기록과 경기 중 피로에 반영됩니다. 관전의 공은 현재 패스·돌파·슈팅 장면에 맞춰 이동합니다.

### 편의성 및 경기 관전 패치

- 포지션 탭(GK/DF/MF/FW)을 고르면 같은 분류의 세부 포지션만 선택할 수 있습니다. 분류를 바꿀 때 맞지 않는 세부 선택은 해제되며, 전체 선수 탭은 포지션 조건을 초기화합니다.
- 리그 휴식 주간은 다음 경기 직전까지 한 번에 진행합니다. 우리 팀 리그가 끝났다면 남은 시즌 일정을 정산한 뒤 **다음 시즌 시작**으로 연결합니다. 컵 경기 결과와 처리한 주 수를 표시하며, 휴식 중에도 체력과 부상이 회복됩니다.
- 연속 진행은 시즌에 남아 있는 리그 경기 수까지만 선택할 수 있습니다. 리그가 끝난 상태에서는 남은 시즌 일정 진행을 안내합니다.
- 상단 **연속 진행**에서 1~20개의 리그 경기를 자동 진행합니다. 매 경기 세부 포지션·오버롤·현재 체력을 고려해 선발을 선정하며 컵 경기도 로테이션합니다. 휴식 주간은 경기 수에 포함하지 않습니다. 매주 저장하고, 중지 요청·저장 실패·시즌 종료 시 멈춥니다.
- 선수 프로필과 명단에 GK/CB/LB/RB/DM/CM/AM/LW/RW/ST 및 주발을 표시합니다. 골 결정력·패스·시야·드리블·크로스·태클·마킹·위치 선정·가속력·지구력·몸싸움·헤더·반사신경·볼 처리 14개 능력치를 사용합니다. 기존 커리어의 선수도 유지하면서 세부 특성을 생성합니다. 이 특성은 실제 선수의 공식 평가 데이터가 아닌 게임용 수치입니다.
- 이적시장에 세부 포지션·주발·최대 요구액·최소 오버롤·선택 능력치 최소 필터와 가격 양방향·오버롤·선택 능력치 내림차순 정렬을 추가했습니다.
- 상위 디비전에서 하위 디비전으로 이적하는 선수는 개인 야망과 단계 차이에 따라 높은 주급을 요구합니다. 협상 창에서 구단 이적료와 선수 주급을 각각 제안합니다. 요구 주급보다 낮으면 선수는 거절하고, 수락한 주급은 매주 지급합니다.
- 전술 보드의 **움직임 지시**에서 오버랩·안으로 좁히기·채널 침투·자유 이동, 전진 성향, 개인 패스, 압박을 지정합니다. 지시는 자리별로 저장되어 교체 선수에게 이어집니다.
- 킥오프하면 0분부터 2D 관전 화면을 열고 자동 재생합니다. 기본 속도는 실제 5분에 전반 45분이며 하프타임에 멈춥니다. 후반전도 동일합니다. 3배·10배속, 일시정지, 1분 진행, 남은 경기 자동 진행을 제공합니다. 경기 중 팀 지시·개인 지시·최대 5명 교체를 지원합니다.
- 관전의 선수 점은 전술 위치와 이동 지시를 시각화합니다. 경기 결과는 매 분 선수 능력과 당시 지시를 반영한 확률 모델로 계산합니다. 실제 선수 충돌과 공 궤적을 계산하는 물리 엔진은 아닙니다. 경기 중 저장은 5분 단위 및 지시·일시정지 시 수행하며, 불러온 경기는 멈춘 상태에서 재개합니다.

## 데이터와 범위

팀 수와 디비전 형식은 2026/27 시즌에 발표된 리그 구조를 기준으로 정리했습니다. 시즌마다 승격·강등, 재정 규정, 그룹 편성으로 실제 참가 팀 수가 바뀔 수 있습니다.

상용 Football Manager와 무관한 독립 게임입니다. 실제 구단 이름과 일부 최신 선수단 이름을 활용하지만 능력치, 예산, 경기 결과는 시뮬레이션용입니다. 공식 시즌 데이터나 라이선스 로고를 사용하지 않습니다.

경기는 전술·선수 능력·체력·사기·홈 이점에 기반한 확률 모델입니다. 3D 경기, 분 단위 직접 조작, 국가대표, 에이전트 세부 조항, 멀티플레이는 포함하지 않습니다. 국내 FA컵, 32팀 유럽 챔피언스 컵·유로파 컵, 12개국 1~3부 승강제는 포함합니다. 팀 운영에 집중한 로컬 감독 모드입니다.

브라우저 저장은 실행 주소별로 분리됩니다. 파일로 열 때와 로컬 서버 주소로 열 때의 저장은 별개이므로, 옮기려면 사이드바 하단 `나의 감독 커리어`에서 JSON을 백업하고 복원하세요. 브라우저 데이터를 삭제하면 자동 저장도 삭제됩니다.
