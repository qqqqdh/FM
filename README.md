# TOUCHLINE

설치와 회원가입 없이 브라우저에서 실행하는 한국어 축구 감독 시뮬레이션입니다.

## 실행

`index.html`을 Chrome 또는 Edge로 열거나 `게임 시작.bat`을 더블클릭하세요.
이 채팅에서 실행 중인 미리보기: http://127.0.0.1:8765

직접 서버를 실행하려면 이 폴더에서 `python -m http.server 8765 --bind 127.0.0.1`을 사용하세요.

## 감독 커리어

- 12개국 모두 1~3부를 제공. 잉글랜드(20/24/24), 스페인(20/22/40), 독일(18/18/20), 이탈리아(20/20/60), 프랑스(18/18/18), 포르투갈(18/15/19), 네덜란드(18/20/18), 벨기에(18/15/16), 튀르키예(18/20/36), 스코틀랜드(12/10/10), 브라질(20/20/20), 대한민국(12/17/15) 팀 형식을 사용합니다.
- 총 12개국·36개 리그·727개 구단·15,994명의 선수가 동시에 진행됩니다. 2026/27 기준으로 잉글랜드의 선덜랜드(1부)·레스터 시티(3부), K리그1의 FC 안양, K리그2 17개 팀을 반영했습니다. 스페인·이탈리아·포르투갈·튀르키예의 다중 그룹 3부는 그룹별 홈 앤드 어웨이 일정으로 시뮬레이션합니다.
- 선덜랜드·레스터 시티·FC 안양은 공식 2026/27 선수단 이름을 우선 사용하고, 나머지 구단은 동일한 게임 규칙을 유지하는 생성 선수로 채웁니다.
- AI 구단 간 이적, 시즌별 성장과 노화.
- 현금 이적, 역제안, 선수와 현금 트레이드, 매각 제안, 시즌 임대 및 복귀.
- 재계약, 주급 및 계약 보너스, 출전 비중 약속, 계약 만료와 자유 계약.
- 5개 포메이션, 선발 변경, 선수별 공격·지원·수비 임무, 주장, 전술 프리셋.
- 성향, 압박, 템포, 폭, 수비 라인, 패스 방식, 공격 전개 설정.
- 전반 시뮬레이션 → 하프타임 팀 토크·전술 조정·최대 5명 교체 → 후반전.
- 점유율, 슈팅, 기대 득점(xG), 득점 이벤트, 전체 일정 및 리그 테이블.
- 훈련 계획과 강도, 체력, 사기, 개인 면담, 부상, 경고 누적 출장 정지.
- 스카우팅과 잠재력 보고서, 관심 선수, 유소년 입단 및 1군 승격.
- 코치·스카우트·의무팀, 훈련·유소년 시설 확충.
- 이사회 목표와 신뢰도, 주급, 경기 수입, 상금, 다음 시즌 지원금, 재정 장부.
- 브라우저 자동 저장 및 JSON 저장 파일 백업·복원.

이적시장: 1~5라운드, 12~14라운드. 스쿼드 최대 25명. 시즌 임대료는 완전 이적 요구액의 20%이며 주급을 추가 부담합니다. 계약은 표시된 연도의 새 시즌이 시작될 때 만료됩니다. 핵심 선수로 약속한 선수가 출전하지 못하면 사기가 하락합니다.

## 데이터와 범위

팀 수와 디비전 형식은 2026/27 시즌에 발표된 리그 구조를 기준으로 정리했습니다. 시즌마다 승격·강등, 재정 규정, 그룹 편성으로 실제 참가 팀 수가 바뀔 수 있습니다.

상용 Football Manager와 무관한 독립 게임입니다. 실제 구단 이름과 일부 최신 선수단 이름을 활용하지만 능력치, 예산, 경기 결과는 시뮬레이션용입니다. 공식 시즌 데이터나 라이선스 로고를 사용하지 않습니다.

경기는 전술·선수 능력·체력·사기·홈 이점에 기반한 확률 모델입니다. 3D 경기, 분 단위 직접 조작, 국가대표, 에이전트 세부 조항, 멀티플레이는 포함하지 않습니다. 국내 FA컵, 32팀 유럽 챔피언스 컵·유로파 컵, 12개국 1~3부 승강제는 포함합니다. 팀 운영에 집중한 로컬 감독 모드입니다.

브라우저 저장은 실행 주소별로 분리됩니다. 파일로 열 때와 로컬 서버 주소로 열 때의 저장은 별개이므로, 옮기려면 사이드바 하단 `나의 감독 커리어`에서 JSON을 백업하고 복원하세요. 브라우저 데이터를 삭제하면 자동 저장도 삭제됩니다.
